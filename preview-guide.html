Two parts, one cohesive project.

Some advanced experiments need extra setup.

Feature detection supports SIFT and ORB immediately. True SURF requires OpenCV built with nonfree support. YOLO11 and DeepLabV3 use separately installed deep learning libraries and pretrained model weights. LFW Eigenfaces may download data on first use. The custom YOLO training/validation stage must be performed separately and documented using your real dataset and metrics.
